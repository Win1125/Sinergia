## DESCRIPCIÓN

Sistema CRUD completo para gestión de pacientes desarrollado en Laravel 12 con autenticación JWT. Incluye API RESTful y frontend con Bootstrap 5.

## CARACTERÍSTICAS

- ✅ Autenticación con JWT
- ✅ CRUD completo de pacientes
- ✅ Validaciones (servidor + cliente)
- ✅ Búsqueda y paginación
- ✅ Interfaz responsive
- ✅ Pruebas unitarias con PHPUnit
